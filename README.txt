# Arthaśāstra Cryptography Website

## How to run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html` to open it in Chrome/Edge.
3. Internet is only needed for the Google Fonts used by the design; the website itself works without a backend.

## Features
- Responsive modern UI
- Animated mandala/hero section
- Scroll reveal animations
- Dark/light theme
- Substitution cipher demo
- Simple transposition cipher demo
- Decryption and copy buttons
- IKS learning cards
- 5-question interactive quiz

## Academic framing
The project demonstrates the Arthaśāstra topic from the supplied IKS syllabus, especially secret communication, substitution/transposition, coded messaging and information protection. The cipher algorithms are deliberately simple modern educational demonstrations and are not claimed to reproduce a specific historical Arthaśāstra cipher.
